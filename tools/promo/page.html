大模型推理成本一年下降十倍，工程侧发生了什么

2026-11-05 · 深度长文 · 阅读 8921 · 约 12 分钟

过去一年，推理侧的单位 token 成本下降了接近一个数量级。这个变化并不是单一技术突破带来的， 而是模型结构、量化、KV Cache 管理、批处理调度和硬件利用率共同作用的结果。

先看最容易被忽视的一环：批处理调度。连续批处理把请求的调度粒度 从「整批」下沉到「单步」，让 GPU 在等待某个请求生成时不会空转，实际吞吐提升往往在两倍以上。

示意图：请求调度时序对比

其次是 KV Cache 的显存管理。分页式 KV Cache 借鉴了操作系统虚拟内存的思路， 把显存切成固定大小的块按需分配，显存碎片率显著下降，能同时挂载的会话数也随之上升。

这些优化叠加起来，才让「每百万 token 几块钱」成为可能。便宜下来的推理， 又反过来改变了产品设计——长上下文、多轮反思、批量生成，都不再是奢侈品。
